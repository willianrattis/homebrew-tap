# willianrattis/homebrew-tap

Homebrew tap for apps by [@willianrattis](https://github.com/willianrattis).

## GH Switcher

Switch your GitHub CLI account from the macOS menu bar.

```bash
brew trust willianrattis/tap
brew install --cask willianrattis/tap/gh-switcher
```

The GitHub CLI (`gh`) is installed automatically as a dependency.
More at [willianrattis/gh-switcher](https://github.com/willianrattis/gh-switcher).
